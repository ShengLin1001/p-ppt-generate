# P Academic PPT

给 PJ 做学术汇报 deck。视觉基准 = `assets/reference-deck.pptx`（从一份浙大应用力学所的
博士答辩 deck 抽出、已匿名化的 10 页版式骨架），叙事基准 = Assertion–Evidence 的中式答辩变体。

**本 skill 只管从零做新 deck。** 审阅已有 deck 或只做美化时，用第 5 节的质检门 + 第 3 节的
单页法则当清单，不要走克隆流程。

## 铁律

1. **模板是 source of truth**：版式、字号、配色一律从参考 deck 克隆，不重新设计、不加装饰。
   参考 deck 只读——要改先复制。
2. **放不下就删文字或拆页，绝不缩字号**。字号阶梯是视觉层级本身，破了层级整页就散。
3. **每页必须有断言句**。没有断言句的页 = 没想清楚要证明什么，退回重写，不要先排版。
4. **不进生图管线**。公式、数据、图注必须可编辑可校对；概念示意图缺失就留占位框标注
   「待补图：<内容>」，不要用文生图糊上去。

## 1. 先定骨架，再碰 PPTX

顺序不能反：**叙事 → 版式计划 → 克隆 → 填内容 → 质检**。先建 PPTX 再想讲什么必返工。

**页数预算**：汇报分钟数 × 1.2 页（35 min 博士答辩 ≈ 42–47 页；15 min 组会 ≈ 18 页）。
超出预算就砍章节，不要靠压缩单页密度。

**Ghost deck 测试**（交付前必跑）：把每页的断言句按顺序抽出来读一遍，应当自成一条完整论证链
——问题 → 为什么难 → 怎么做 → 证据 → 所以呢。读不通就是结构问题，改结构别改排版。

**章节骨架**（答辩缺省，按实际研究调整）：

```
封面 → 目录 → [章节扉页 → 内容页 × n] × 章节数 → 总结与展望 → 主要成果 → 致谢页
```

研究背景章内部按 `领域是什么 → 典型应用 → 现有方法 → 现有理论 → 挑战与创新 → 本文内容总览`
推进；成果章内部按 `问题与方案 → 方法/模型 → 验证 → 机制解释 → 小结` 推进。

## 3. 单页法则（Assertion–Evidence 的中式答辩变体）

该样板与英文 A–E 的差别，是把 message title 拆成了**两层**：标题栏只做导航，断言句另立横幅。
新 deck 照此办：

每页必须同时具备——

1. **标题栏**：`章节号 ｜ 章节名 ｜ 页主题`。这是导航，写主题标签即可，**不要**写成结论句。
2. **断言句**：一页有且只有一句总结论，放在三处之一——
   - **页顶横幅**（最常用）：做了什么 + 得到什么结论，关键短语标红；
   - **页底 ✓ 行**：1–2 条，收"所以呢"；
   - **侧栏竖排**（版面被图阵占满时）。
   顶幅与底行可以并存：顶幅写"这页在干什么"，底行写"于是得到什么"。
3. **证据**：图 / 表 / 公式占据中部 ≥60% 版面。一个面板 = 一个 exhibit，面板旗标写这个
   exhibit 是什么，图下灰条写子图是什么。
4. **引文**：凡用他人图，页底 10pt 行写 `作者 (年份) 期刊`，一图一条。

**信息密度上限：每页 ≤3 个核心信息。**超了就拆页。被砍掉的细节写进演讲者备注，不要塞回版面
——备注是信息的去处，不是垃圾桶，每页都要有口播稿。

**量化成果前置**：有数就把数写进断言句（"粘附能提高 3.4 倍"胜过"粘附能显著提高"）。

## 4. 版式表与克隆

`assets/reference-deck.pptx` 的 10 页即 10 种版式。它是**填好内容的样板**不是空模板——
克隆后逐一替换文本，残留的样板词由质检门第 3 关兜底。

| 页 | 版式 | 用途 |
|---|---|---|
| 1 | 封面 | 标题 / 汇报类型 / 答辩人 / 导师 / 单位 / 日期 |
| 2 | 目录 | 6 条编号条目，左侧竖排「目录」 |
| 3 | 三面板 + 旗标 + 逐图引文 | 文献综述、现有理论对比 |
| 4 | 流程总览（多行章节框 + 箭头链 + 双色主线） | 本文主要研究内容 |
| 5 | 章节扉页 | 目录版式的高亮变体，当前章加深其余淡出 |
| 6 | 顶幅断言 + 双面板 + 底部 ✓ 行 | **内容页主力版式** |
| 7 | 图阵（(a)–(h) 编号）+ 右侧竖排断言 | 一页放 6–8 张子图的结果页 |
| 8 | 四栏总结（每栏 ✓ 结论 + 底部创新点标签） | 总结页 |
| 9 | 纯文本列表页（顶部横线 + 编号条目） | 读博期间主要成果、参考文献 |
| 10 | 致谢/结束页 | 「敬请各位老师批评指正！」 |

克隆（PowerPoint COM 原生复制，保真度高于 python-pptx 重绘）。下文 `<skill>` 指本 skill 目录
（Claude Code 走 `.claude/skills/p-ppt-academic/`，Codex 走 `.agents/skills/p-ppt-academic/`，两份内容相同）：

```powershell
& <skill>/scripts/clone_pages.ps1 -path_ref <skill>/assets/reference-deck.pptx `
    -path_out <工作目录>/deck.pptx -plan "1,2,5,3,4,6,6,7,5,6,8,9,10"
```

填内容用 python-pptx（venv：`~/mysoft/env/pyenv/codex/Scripts/python`），逐 run 改文本。

## 5. 质检门（每轮必过，四关）

```bash
# 1–3 关：几何越界 / 文字溢出 / 样板残留词 / 数字与语料交叉核验
~/mysoft/env/pyenv/codex/Scripts/python <skill>/scripts/qa_check.py \
    -deck <工作目录>/deck.pptx -source <内容语料.md>
```

```powershell
# 第 4 关：COM 渲染导出 PNG，逐页目检
& <skill>/scripts/export_png.ps1 -path_deck <工作目录>/deck.pptx -path_out <工作目录>/qa
```

PNG 必须真的逐张看（Read 工具读图），程序化检查抓不到的：图文错位、面板留白失衡、
旗标压住图、配色跑偏、断言句和图讲的不是一件事。

**数字交叉核验**（qa_check 第 3 关）会把页面上语料里查不到的数据型数字全部列出来。
这一关拦的是最贵的错误——答辩现场被问到一个自己编出来的数。

交付前再手过两项：Ghost deck 测试（§1），以及每页备注是否都有口播稿。

## 6. 陷阱

- **python-pptx 改文本必须在 run 级改**。给 `paragraph.text` / `shape.text` 赋值会清掉
  字号、颜色、加粗，整页字回落到母版默认。
- **克隆页里的组合形状内部也有文字**。替换时要递归进 `shape.shapes`，否则目录条目、
  流程框里的样板词留在页面上——`qa_check.py` 的 `get_shape_text` 已按此递归。
- **页码是静态文本**（`  / 46`），总页数变了要逐页改，不会自动跟随。
- **PowerShell 5.1 按 GBK 解析无 BOM 的 .ps1**，中文路径会乱码。工作目录用 ASCII 路径，
  或给 .ps1 加 BOM。
- **git-bash 内联 PowerShell 会吃掉 `$`**：一律 `PowerShell` 工具直接跑，或 `-File` 执行脚本，
  不要在 bash 里拼 `powershell -Command`。此外 git-bash 里没有 `powershell.exe`，用
  `PowerShell` 工具或 `& <脚本路径>`。
- **COM 的 `Presentations.Open` 要绝对路径**，相对路径静默打开失败。
- **COM 进程要 `Close()` + `Quit()`**，漏了会留下 POWERPNT.EXE 占住文件，下一轮写入被拒。
- **公式**：参考 deck 用的是行内图片。新 deck 优先用 Unicode 文本行（`σ`、`Δβ`、`≫`、下标
  `ᵢ`），保证可校对；实在写不了的再截图，并在备注里留 LaTeX 源。
